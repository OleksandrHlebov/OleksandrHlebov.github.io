Vulkan C++20 Library

A Vulkan API wrapper library built using the experience acquired from earlier projects, aiming to make it a much more polished project. Created using modern C++20.

Utilizes commonly used Vulkan libraries: vk-bootstrap and VulkanMemoryAllocator.

Uses a builder pattern for creation of Vulkan handles, and manages the lifetime of objects automatically using deletion queues.
